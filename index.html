Features

Everything you need for a sharp README

Every setting you change in the builder is encoded into the URL. The API produces exactly what you saw in the preview — no surprises.

📊
GitHub Stats Card
11 selectable metrics. Row list or 3×N grid layout. Customise title, icons, border, and more.
🔗
Social Links Card
Add any profile URL and the card auto-detects the platform. Flow or grid layout. Drag to reorder.
🎨
9 Themes + Custom
Pick from 9 polished presets or create your own with 6 independent color slots.
🔵
Icons Only Mode
Compact square icon badges with no label text — great for minimal profiles.
⚡
Serverless — zero config
Runs on Vercel. No backend to manage. Embed a URL and it just works.
🔒
Single URL contract
Preview and embed are generated from the exact same URL. What you configure is what your README shows.

Widgets

How it works

Three steps, one URL

No accounts, no sign-in. Just configure, copy, and paste.

1
Open the builder
Enter your GitHub username, pick a theme, select your stats, and tweak every option in real time.
→
2
Copy the embed
Grab the Markdown, HTML, or raw URL from the output panel. The URL encodes your entire configuration.
→
3
Paste into your README
Drop it into your GitHub profile README. The SVG renders live with your real data, cached for 5 minutes.
README.md Markdown 

![GitHub Stats](https://readme-maker-ashen.vercel.app/api/stats?username=yourname&theme=midnight&radius=8)


![My Links](https://readme-maker-ashen.vercel.app/api/social-card?link=https://github.com/yourname&title=Connect+with+me&centreTitle=1)

Open Source

Built in the open — contributions welcome

Readme Maker is fully open source. Whether it's a new theme, a platform badge, a bug fix, or just a ⭐ star — every bit helps.

🎨
Add a theme
Drop a new entry into src/core/themes.js with 6 hex values and it automatically appears in the builder and as a URL param.
🔗
Add a platform
Add a new entry to src/widgets/social-links/platforms.js with a match pattern, color, and SVG icon path.
📊
Add a metric
Extend stat-definitions.js and the GitHub GraphQL query to surface a new stat in the stats card.
🐛
Report a bug
Found something broken? Open an issue on GitHub with steps to reproduce and we'll get it sorted.
Ready to contribute? Fork, branch, build, PR. The repo has a full test suite and a local dev server to make it easy.
